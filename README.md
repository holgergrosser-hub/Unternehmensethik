# Unternehmensethik - Online-Unterweisung

Online-Unterweisung zu Unternehmensethik, Compliance und verantwortungsvollem Geschäftshandeln.

## 📋 Inhalt

Die Schulung umfasst 11 Lernmodule:

1. Einleitung
2. Korruptions- und Geldwäschebekämpfung
3. Datenschutz und Datensicherheit
4. Finanzielle Verantwortung
5. Offenlegung von Informationen
6. Fairer Wettbewerb und Kartellrecht
7. Interessenkonflikte
8. Plagiate
9. Geistiges Eigentum
10. Ausfuhrkontrollen und Wirtschaftssanktionen
11. Whistleblowing und Hinweisgeberschutz

## 🎯 Abschlusstest

- 10 Multiple-Choice-Fragen
- Bestehen ab 70% (7 von 10 richtig)
- Zertifikat bei Bestehen

## ⏱️ Dauer

ca. 20-30 Minuten

## 🚀 Deployment

1. Repository auf GitHub erstellen
2. Mit Netlify verbinden
3. Automatisch live!
